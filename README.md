# BomberBird

BomberBird is a single-player reinterpretation of a classic grid action game, built for the final project of an introductory Unity game development course.

The game uses Israeli birds and habitats as its original theme: the player controls a bird moving through compact grid arenas, placing timed seed pods instead of bombs to clear obstacles and hazards and reach the exit.

## Status

This project is currently awaiting GDD and concept approval. Gameplay development has not started.

The full design proposal is available at [Docs/GDD.md](Docs/GDD.md).
